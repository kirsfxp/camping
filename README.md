# Кемпинг «Тихая гавань»

## Тема
Веб-приложение для учебного бронирования мест в кемпинге (Карелия). Визуальный стиль вдохновлён сайтом «Чайкин остров»: крупная типографика с засечками, природные оливковые цвета, темная схема с парящими предметами и коллажная шапка с фотографиями.

## Запуск
Откройте папку проекта в VS Code и запустите `index.html` через расширение Live Server. Из-за использования ES-модулей открытие через `file://` не сработает, нужен HTTP-сервер.

## Функции
- Интерактивная схема и список, построенные из единого массива данных (8 объектов, 2 изначально заняты).
- Два фильтра: по вместимости и максимальной цене.
- Выбор места с клавиатуры (Tab/Enter) и мышью.
- Подсчёт итоговой стоимости (цена за ночь × количество ночей).
- Валидация формы (гости не превышают вместимость, ночи от 1 до 30).
- Защита от дублей при бронировании.
- Сохранение в localStorage, восстановление при перезагрузке.
- Отмена броней и сброс всех записей.
- Переключение языка интерфейса (Ru/Eng).
- Адаптивный дизайн (360, 768, 1280 px).

## Ограничение учебного бронирования
**Учебное демо:** бронирования сохраняются только в этом браузере. Реальная бронь не оформляется, оплата не взимается.

## Источники изображений
- Фотографии Карелии и чайки взяты из открытых источников для образовательных целей.
- Иконки на схеме — стандартные эмодзи.
